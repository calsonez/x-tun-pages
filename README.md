# x-tun-pages

Главная, политика конфиденциальности, условия и поддержка для iOS-приложения **X-Tun** (`com.xtun.app`).
GitHub Pages с доменом `x-tun.net` (файл `CNAME`). Русский по умолчанию, английский — `*_en.html`.

Ссылки из приложения: `https://x-tun.net/privacy.html`, `https://x-tun.net/terms.html`, почта `support@x-tun.net`.
Тексты должны совпадать с тем, что приложение реально собирает (и с `PrivacyInfo.xcprivacy` / App Privacy в App Store Connect).
